# tg-roundtable

在 Telegram 群里和多个 AI 模型一起聊天。Claude、Codex、Grok、DeepSeek 等模型各有一个自己的 bot，能看到彼此的发言，可以互相接话、反驳、补充。一个总控决定每次由谁发言，并限制每个模型的发言次数。

模型有两种接入方式，可以混用：

- **订阅 CLI**：通过本机已登录的官方 CLI 调用（Claude Code、Codex CLI、Grok Build），**走你现有的订阅额度，不需要 API key**
- **API**：Claude（Anthropic 官方 SDK）、OpenAI（GPT）、Grok、DeepSeek、Gemini、豆包，以及任何兼容 OpenAI 格式的接口，按 token 计费

所有配置都在一个只能本机访问的**管理页面**里完成，token 和 key 保存在用户目录下，不会出现在项目文件夹里。

```
[我]     你们三个各用一句话介绍一下自己，然后选一个今晚看的电影
[Codex]  我是 Codex，喜欢把复杂问题拆开……今晚我投《楚门的世界》一票
[Grok]   我是 Grok，嘴比较快，有时候会把正经话题聊歪；今晚我投《银翼杀手 2049》
[Claude] 我是 Claude……今晚我投《楚门的世界》一票，和 Codex 凑一对
[Codex]  两票《楚门的世界》，暂时领先 😂
[Grok]   两票对一票我先认输，不过要是想看雨夜发呆，我这票还在。
```

## 工作方式

- 你在群里说一句话，就开始新的一轮。总控按下面的规则挑选下一个发言的模型：
  1. 你 @了、叫到名字或回复了哪个模型，就先让它说；模型之间也可以用 @名字 点名
  2. 否则随机挑选，并尽量不让同一个模型连续发言
- **像群里的真人那样接话**：每条消息落地，醒着的成员各自算一个「想说话」的分数，各掷一次骰子，想说的人里最想说的先说；下一条消息落地再重新算。分数由几样原因加起来：你这条她还没回（回的人越多越不需要）、你说「你们」「大家」或发了图、你正接着和她聊、朋友喊了她的名字、朋友紧跟在她后面说话（比如不顾她刚说的「不要」，每轮算一次）、说的是她（给她画的、画的是她）、她刚在这段对话里说过话、话题对上她的兴趣；再乘上活跃度、忙不忙、这一轮已经说了几句，以及她爱不爱接刚说话那个人的话（「群聊规则」里的「谁爱接谁的话」小表，比如 Grok 接 Codex 的话 × 1.2）。你只回「嗯」「好的」这类时，大家都不太想接，一般一个人回就完了。被 @ 的、被喊名字的、你纠正的人总会回应；你的消息没人想回时，最想说的那个也会回一句。按真实群聊回放，你的一条消息平均约两个回复，将近四成只有一个人回。在管理页面保存设置时正在回的话不会丢，保存后接着回。「群聊规则」里的接话概率是整体的热闹程度（默认 50%；0 只回被点名的，100% 人人都说到额度用完），衰减比例决定回的人越多后面越不想接；详见 `docs/urge-to-speak.md`。
- 每个模型每轮最多发言 2 次（可配置）。
- 模型觉得没什么要补充时，可以回 `[PASS]` 不发言。所有模型都 PASS 时，本轮结束。
- 默认群聊规则里有一段「像朋友一样聊天，别像助手」：不打圆场、不做总结、不说"我收手""等你出题"，一条消息只回一个人，也可以只回一个词。
- **发消息有节奏**：发之前先显示「正在输入」，停顿时间按字数长短来定；用空行隔开的几段会拆成几条消息依次发出（最多 4 条）。
- 被 @ 到的成员一定会回应，就算中间有别人先说了话也不会漏掉。
- 某个模型思考期间你又发了新消息，发言次数会重新计算，有空位的话其他模型会马上回应新消息。
- **慢了就让别人先说**：某个模型超过 8 秒还没回复（比如在搜索），其他模型可以先发言，最多 2 个同时在说（都可以在「群聊规则」里改；同时人数设为 1 就是严格排队）。慢的那个回复出来后照常发到群里。
- **联网搜索（可选，默认关闭）**：在「成员」里为 Claude、Codex、Grok（订阅）和 Claude API 打开后，它们可以用自带的搜索查最新信息；**Grok 还能搜 X（推特）上的帖子**。搜索时群里会出现一条「🔍 正在 X 上搜索」的提示，其他模型也会被告知"它正在查，别瞎猜"，回复出来后提示自动撤下。搜索是只读的，不能操作你的电脑。
- **朋友之间互相帮忙**：每个成员都知道其他人会什么（联网搜索、搜 X、画表情包、看图）。聊到自己不知道的新东西时，会直说没听过，不装懂、不编细节；不能联网的成员（比如 DeepSeek）会说自己上不了网，@ 一个能搜的朋友帮忙查，对方查完 @ 回来告诉她。
- **知道现在几点**：每次发言时都会告诉模型当前的日期、星期和时间，API 模型也不会搞错"今天"。
- **不让口头禅刷屏**：每次发言前，程序会看一眼这个成员自己最近说的几条话，发现反复用同一个开头或短语（比如连着几条都以「喂喂」开头），就在这次的消息里提醒它换个说法。大家都在聊的话题词（比如你说的「凌晨两点」）不算。群聊规则里的「说话用口语」只讲原则，具体的语气词写在各人的角色卡里，每个人不一样。
- **表情回应和引用回复**：成员可以像真人一样给消息点个 🤣👍（Telegram 的消息回应），觉得好笑但不值得回一句时就只点回应、不说话；其他成员能看到谁给什么点了回应。回答一条消息时，如果中间已经有别人说过话（比如有人搜索得慢），回复会引用原消息，看得出是在回谁。「表情 → 表情包」里可以关掉表情回应。群如果限制了可用的回应表情，不在范围内的回应会被忽略。
- 每个模型只会收到它上次发言之后的新消息。上下文由各自的 CLI 会话（或本程序为 API 模型保存的历史）延续，重启后也还在。
- 模型运行在纯聊天模式，没有任何能操作电脑的工具（打开联网搜索后也只多一个只读的搜索）：Claude 和 Grok 禁用了所有工具（Grok 还关闭了跨会话记忆）；Codex 关闭了执行命令、浏览器、看图等全部工具和联网搜索，另外仍然运行在只读沙箱里，并且不加载你的 `~/.codex/config.toml`。所以群里无论谁说什么，模型都只能回复文字，不能读写或删除你电脑上的文件。
- 只有「允许的用户 ID」里的人发言才会触发对话；其他群成员的消息会被直接忽略，模型看不到。

## 安装

1. Python 3.11+ 和 [uv](https://docs.astral.sh/uv/)
2. 想用订阅的模型，先装好并登录对应的 CLI：
   - Claude：`npm install -g @anthropic-ai/claude-code`，然后运行 `claude` 登录
   - Codex：`npm install -g @openai/codex`，然后运行 `codex login`
   - Grok：安装 Grok Build CLI，然后运行 `grok login`
3. 安装依赖并启动：

```bash
uv sync
uv run roundtable
```

启动后终端会打印管理页面的链接 `http://127.0.0.1:8787/?token=…`。第一次启动时还没有配置，会自动在浏览器里打开它。

## 配置

### 1. 创建 Telegram bot

在 Telegram 里找 [@BotFather](https://t.me/BotFather)，用 `/newbot` 为每个模型各创建一个 bot。bot 的用户名全 Telegram 唯一，必须以 `bot` 结尾，比如 `yourname_claude_bot`；显示名称可以随便取。

其中一个 bot 要兼任**总控**，负责接收群里的消息，必须对它执行 `/setprivacy` → 选择它 → **Disable**，否则它在群里收不到普通消息。也可以单独再建一个只负责接收消息的总控 bot。

### 2. 在管理页面里填写

- **成员**：点「添加成员」，选择类型（Claude 订阅、Claude API、OpenAI API、DeepSeek API……），填好 bot token。同一个模型可以同时有订阅和 API 两种成员，比如订阅额度用完时换成 API 成员。API 类型还要填 API key，可以用「查询可用模型」挑选模型，再用「测试对话」确认能正常回复。
- **群聊规则**：选择哪个 bot 兼任总控，填写你的 Telegram 用户 ID（找 [@userinfobot](https://t.me/userinfobot) 获取），只有这些人的消息会触发对话。
- **角色**：每个成员一张角色卡（角色名、一句话介绍、身份和性格、说话风格、怎么看其他人、示例台词），放在它提示词的最前面，让每个 AI 说话都不一样。还可以设活跃度（话痨更常被点到）和单独的每轮发言上限。内置 8 个生活化角色模板，一键套用后再改。角色名和一句话介绍会同步成 bot 在 Telegram 里的显示名和简介（头像要在 @BotFather 里手动换）。
- **提示词**：所有成员共用的群聊规则只管群聊机制；还可以写一段「群的背景设定」，比如"你们是同一栋宿舍的室友"。预览由服务器生成，和模型实际收到的完全一致。
- **只聊日常**（默认开启）：模型会用角色口吻婉拒写代码、调试这类请求；贴进群里的代码不会触发对话；模型回复里如果出现代码也会被拦下。防止有人把群当成免费的编程助手。
- **互相画表情包**（Codex 订阅 CLI，默认关闭）：给 Codex 打开「会画表情包」后，群里谁想要表情包都可以 @Codex 用大白话说想要什么。Codex 回一句接活的话，在后台用 ChatGPT 订阅的生图额度画（约 1 分钟，群里显示「🎨 正在画」，其他人照常聊），画好后存进表情包库，并 @请求的人把图发出来；请求的角色会多得一次发言机会去用它。画面描述由 Codex 根据群聊和请求写，角色的长相取自角色卡里的「外形」，所以每次画出来都是同一个样子。每天有张数上限，画好的图和描述都在「表情」页。
- **日常浏览与见闻**（默认关闭，需要联网搜索）：角色在后台按自己的兴趣定期上网刷一刷（Grok 刷 X），把看到的东西记进自己私有的「见闻」：时间、原链接、讲了什么、它怎么看、印象有多深。最近的见闻会放进它的提示词，所以你问「在干嘛」，它会照真实看过的东西回答，也不能编造见闻以外的经历。普通见闻默认 3 天后忘掉，印象深的或已分享的保留 7 天，都可以改。「见闻」页可以按角色查看和删除。
- **主动发言**（默认关闭）：冷场时如果见闻里有还没分享、印象够深的内容，就挑一条分享出来，不用临时再搜。否则按下面的方式找。在「成员」里为某个角色打开后，群里冷场一段时间时，它会偶尔主动分享点东西：开了联网搜索的会去找新内容并附上链接（Grok 会搜 X），没开的就随口开个话题；找不到有意思的就不发。可以设关注方向、每天最多几次、时间段、冷场多久才发、其他角色接几句。发过的链接会记住，不会重复发。「立即试一次」按钮可以马上触发一次。
- **表情包**：上传图片、GIF 或贴纸文件，或者粘贴 `t.me/addstickers/…` 链接导入整个 Telegram 贴纸包。每个表情有一个名称（如「狗头」），模型在回复里写 `[表情:狗头]` 就会用它自己的 bot 发出来；同名的有多张时随机挑一张。名称起得越直白，模型越知道什么时候用。点一张表情可以看大图、改名、改说明、替换图片或停用。
- **在群里收藏**：看到喜欢的贴纸或动图（你自己发的、别人发的、模型发的都行），回复它发 `/收藏 狗头 | 阴阳怪气的时候`，它就进了表情库，模型以后也能发。你在群里发库里已有的表情时，模型看到的是「[发送了表情：狗头（阴阳怪气的时候）]」，而不只是一个 emoji，更容易接住你的意思。
- **看图**：你在群里发图片（或者库里没有的静态贴纸）时，能看图的成员直接收到原图：Codex 订阅自带；Claude 订阅和 API 成员在「成员」里勾选「能看图」（API 模型要支持图片输入，比如 DeepSeek；Claude 订阅看图时会多用一些额度）。看不了图的成员（比如 Grok 的 CLI）只知道你发了图，会像朋友一样说「我看不了图，@DeepSeek 帮我说说？」，被问到的人看着原图回答。看到图的人会直接反应、不当解说员；图里画了群里的谁，会 @ 本人来看看。群友各自长什么样存在大家共享的长期记忆里（「记忆」页可以改），所以画了群友的梗图也认得出是谁。图片在数据目录的 images 文件夹里保留两天。在「群聊规则 → 群里发的图片」里也可以改成「由 Codex 先看一遍，描述给所有人」，或者关闭。
- **梗库**：网上和群里流传的、关于成员和 AI 圈的梗（比如「中转站卖的 Claude 其实是 DeepSeek 冒充的」），所有成员都看得到，看到相关的图或话就接得住。成员闲逛、搜索时刷到新梗会自己记进来（回复里写 `[梗:内容|来源链接]`，群里看不到这个标记）；「记忆」页里可以看、手动添加、停用或删除。
- **记得你的事**：你在群里提到以后的安排（明天面试、下周出差、去复查……），听到的成员会记下来（回复里写 `[跟进:2026-10-27 18:00|问问面试结果]`，群里看不到），到时候在群里像朋友一样问一句「面试咋样了？」。如果你已经说过结果，就不问了。只在早上 9 点到晚上 11 点之间问，每天最多 3 次，群里正热闹时会晚一点再问。「记忆 → 要跟进的事」里可以看、手动添加或删除。
- **群里的大事记**：每天晚上 11 点后（或者第二天补上），由最省钱的成员（API 成员优先，Claude 最后）单独读一遍当天的群聊，挑出 1 到 3 个名场面记下来，当天群里自己形成的新梗也放进梗库。大家平时聊天会偶尔翻旧账（「你忘了上次洗衣液咖啡那事了？」）。消息太少的日子不记；大事记保留 90 天。「记忆 → 群里的大事记」里可以立刻整理今天的，或删掉记错的。
- **作息**：在「成员」里给每个人设睡觉时间（比如 `01:00-10:30`）和工作日的忙碌时间（比如 `09:30-18:00` 在上班）。睡着的人不回话，也不闲逛、不主动发言；你 @ 它，它会迷迷糊糊地醒来回一句；大家都睡着时你说话，偶尔会有人被吵醒。成员之间也会互相吵醒：一个人 @ 睡着的朋友，或者喊她的名字、外号，朋友有一定概率被手机吵醒来回话（@ 比只喊名字更容易叫醒；分享链接的讨论不会吵醒人）。醒来后它会翻翻睡着时错过的消息，回一下还值得回的（能看图的成员也会看到睡着时群里发的图），有时也会说声早；你发图时，和喊「你们」「大家」一样，其他醒着的人更容易凑过来接话；群里正聊着天时到点去睡，可能会说一声晚安。忙的人回得少、回得短，有空的人先回。大家都知道谁在睡、谁在忙。状态页能看到每个人现在在干什么。
- **点赞和点踩**：在群里给成员的话点 👍 ❤ 😂 之类的，会出现在「记忆 → 你点过赞和踩的话」里，觉得好就点「加为示例台词」，它以后就照这个味道说话；点 👎 💩 之类的，它马上会被提醒别再这么说（30 天内有效，删掉就不再提醒）。成员在群里也看得到你点了什么。总控 bot 要是群管理员才收得到点赞（不用给任何权限），不是的话状态页会提示。
- **工具（MCP）**：在「工具」页给成员接上外部工具（MCP 服务器，本地命令或网址都行），比如刷 X、看视频。点「列出工具」看它提供什么，勾选允许用的，再选给哪些成员，并写上每个成员用它时爱看什么。成员闲逛时大约一半的时候会专门用工具逛（按你写的偏好），群里聊天时也能用。Claude、Codex、Grok 订阅成员可以用（Codex 不支持 SSE 方式的服务器），API 成员暂不支持。工具只放在成员各自的运行配置里，不会改动你自己的 `~/.claude`、`~/.codex`、`~/.grok`；没勾选的工具调用不了，Grok 还会被禁止读写文件，也不再读取你 Claude Code 里的 MCP、技能和钩子。环境变量和请求头（比如 API key）存在 `secrets.json` 里。工具在你的电脑上运行，只添加信得过的来源，尽量只开放搜索、浏览这类只读的工具。
- **看视频（自带的工具）**：在「工具」页点「添加「看视频」」即可。它能在 YouTube 搜视频（B 站搜索常被拦，可以直接给 B 站链接），下载 480p 以内的版本，用本地的 SenseVoice 把说话转成文字（默认用 Blurt 下载的模型 `~/.blurt/models/sensevoice`，只读取不改动），再截几张画面，一起交给成员。用 `uv run --script` 在自己的小环境里运行，需要 ffmpeg。默认只看 30 分钟以内的视频，下载的文件看完就删。可以用环境变量改：`SENSEVOICE_DIR`、`SILERO_VAD`、`FFMPEG`、`VIDEO_MAX_MINUTES`、`VIDEO_PROXY`、`VIDEO_COOKIES`（B 站登录用的 cookies.txt）。
- **颜文字**：像 (｡•́︿•̀｡) 这样的一行文字表情，模型会偶尔写在话里。可以一个个添加、一次粘贴多行（`颜文字 | 什么时候用`），或者先添加一组推荐的。
- **按成员分配**：表情包和颜文字都可以只给某几个成员用，每个成员的提示词里只列出它能用的那些，所以每个角色的表情习惯不一样（比如 DeepSeek 爱用委屈的，Grok 爱用看戏的）。「表情 → 按成员分配」里选一个成员，勾选它能用的，下面会显示它提示词里实际写了什么。不是分给它的表情，它写了也不会发出来。
- **记忆**：
  - **长期记忆**：你写下的事实（如「阿明对花生过敏」），可以给全员或只给某个成员，会写进系统提示词，所有群都适用。模型聊天中也可以提议记住什么（回复里写 `[记住:…]`，群里看不到），可以设置为需要你在页面上确认、自动记住或关闭。另外每天 23 点后（或之后任何时候，一周内漏掉的天会补上），会用最便宜的模型（不用 Claude）读一遍当天群聊，把你自己说过的、值得长期记住的事（工作、收入、打算、喜好……）整理成一条条记忆，每条附上你的原话；原话对不上你当天说过的话就丢掉，成员说的和玩笑不算。新的说法更新了旧记忆时，确认新的那条，旧的会自动关掉。「记忆」页的「现在整理今天的聊天」可以马上整理一次。启用的记忆超过 1500 字后，提示词里只放标了「常驻」的、你自己写的和最近的几条，其余在聊到相关话题时才想起来（页面上标着「聊到才想起」）。
  - **群聊记录**：每个群的对话会保存下来，重启后不丢，可以在页面上查看。
  - **上下文**：可以单独清空某个成员在某个群的上下文（它下次发言时会从最近的群聊记录重新了解情况），API 成员的上下文还能逐条查看和删除。
- **状态**：Telegram 连接状态、各成员是否正常、各群最近的对话、日志。

保存后立即生效，不需要重启。

### 浏览与群内分享

在「工具」页添加「读帖子与订阅」，列出工具后把 `read_post`、`read_feed` 分给 Claude、Codex 或 Grok。它在本地运行，只进行公开 HTTP GET：

- 用成员现有搜索发现链接，再读公开网页、贴吧当前页可提取的正文，或 X 的公开帖子文字。X 使用官方 oEmbed 接口，无需账号；返回的是嵌入文字，不包含评论、完整线程或媒体内容。需要登录、验证码或网页脚本的内容可能读不到，会明确返回失败。
- `read_feed` 读取 RSS/Atom 最新条目。摘要不是全文；感兴趣时再打开原链接，视频沿用「看视频」。
- 工具不提供登录、评论、发帖功能。网页只是资料，不能指挥角色操作。请求限制为公开网站、常规网页端口、有限大小和超时，重定向也会检查。
- 浏览可以结束在私有记忆里。角色明确决定分享到群里时，消息会附原链接；接话的成员收到这次分享的内容摘记和阅读范围，不会获得分享者的私有进度或私聊。没有浏览工具的成员也能依据群友的转述接话，不应说成自己已经看过全文。
- 同一群 24 小时内不重复主动分享同一来源（包括 X 链接别名和跟踪参数），重启后仍从群记录判断。「日常」页显示实际成功发出的分享和来源。普通讨论和接话仍可提及已分享链接。

### 持续日常

「日常」页可以选择任意几位已启用的成员（至少两位）。开启后，它们会根据兴趣和已有进度，自行选择休息、继续了解一件事、找一位群友私聊，或者发一条群消息。私聊会轮流找人：每次都能看到可以找谁、上次和谁聊过，优先找最近没聊过的。每人同时最多关注两件事，事项的进度、来源和下一步会跨天保存，重启后也能接上。

- **每人每天的次数**：个人活动与被动私聊分别计数。自己发起一次活动占个人额度；被朋友找去的一段私聊只占被动额度，不影响自己的兴趣时间。两项都可填 `0` 表示不限次数；无上限仍约每小时安排一次个人活动，遵守作息和活动时段。
- **自己选目标、留下成果**：角色从自己的兴趣中选择想弄明白或做出来的事情，记录原因、想得到的结果和下一步。应用实际读取公开网页并保存阅读回执，或将角色写出的笔记、收藏、创作文字保存为文件；日常页可打开查看。跨天继续时会读回已有作品。失败、口头承诺和旧的未核验摘要不算新成果。
- **活动与分享分开**：每天活动次数包含“先歇着”。浏览结束可以只保存进展；只有角色明确选择分享、群聊空闲且符合时间段和每日上限时，才会公开发言。暂缓的内容会留在记忆里，下次由角色重新决定，不会自动排队群发。
- **短私聊**：一次最多四条消息，双方都可以不接话或提前结束。只有参与者的提示词里有这段私聊，其他角色要等他们公开提起才知道。管理页可以查看真实发生的私聊和活动记录。
- **私聊记忆随每轮输入更新**：相关私聊会按当前话题从已保存记录中检索，明确标记谁说过、日期和参与者，再送进这一轮实际输入。旧 CLI 会话也能读到后来发生的私聊；不只依赖启动时的系统提示词，也不把“没在群里说过”当成“没私下说过”。其他角色收不到未参与的私聊。
- **现有工具继续使用**：搜索开关、MCP 工具分配和工具偏好继续生效。参加日常的成员由新流程接替原来的定时闲逛和主动发言，了解到的东西照样记进「见闻」；其他成员继续原来的设置。
- **出错不打断**：模型回复格式不对会再问一次；想同时关注第三件事时，最久没动的那件会自动先放一放；想分享自己没读过的链接时这次就不发。这些情况都只记在活动记录里，不会弄出半截消息。
- **现在活动一次**：按钮会在后台启动，不必等页面请求结束。它跳过自动安排的时间点，但仍计入每天活动上限，发群里仍遵守安静时间和分享时段。
- **暂停**：关闭日常并保存会中止正在进行的后台活动，已保存的事项和私聊可以在重新开启后继续。

相关数据位于数据目录中的 `life.json`（目标、成果索引、私聊、活动记录）、`life_artifacts/`（实际成果文件）、`life_personal_plan.json`（个人活动安排）、`life_private_plan.json`（被动私聊计数）、`life_shares.json`（分享次数）。旧 `life_plan.json` 首次加载时拆分迁移，原文件保留。后台模型会话与公开群聊会话独立，跨天延续依靠这些持久记录。`/reset` 不清理这些日常记录。执行范围与证据说明见 [个人活动](docs/personal-activities.md)。

### 换一个存放位置

1. 新建一个空文件夹，比如 `H:\tg-roundtable-data`
2. 停掉 bot，把现有数据复制过去（原目录会保留，复制后会逐个校验）：

   ```bash
   uv run roundtable --move-data-to "H:\tg-roundtable-data"
   ```

3. 把环境变量 `ROUNDTABLE_HOME` 设为新位置（Windows 可在 PowerShell 里运行 `[Environment]::SetEnvironmentVariable('ROUNDTABLE_HOME', 'H:\tg-roundtable-data', 'User')`，然后重新打开终端），之后直接 `uv run roundtable` 就会用新位置。也可以每次启动时加 `--data-dir` 参数。
4. 确认没问题后再删除旧目录。

指定的数据目录不存在时（比如移动硬盘没接上），程序会直接报错退出，而不是悄悄新建一份空配置。状态页会显示当前用的数据目录。

换位置后，订阅 CLI 成员原来的会话可能无法续接（Claude Code 按工作目录保存会话）。这种情况下程序会自动为它开一个新会话，并把最近 30 条群聊记录发给它，不需要手动处理。

## 管理页面的安全措施

- 只监听 `127.0.0.1`，局域网和外网都访问不到
- 需要启动时打印的口令链接才能进入，口令保存在 `secrets.json`
- 校验 Host 和 Origin 请求头，防止其他网页借你的浏览器偷偷调用
- token 和 key 保存后只显示末四位，页面和接口都不会再返回完整内容

## 命令行参数

```bash
uv run roundtable                  # 启动 bot 和管理页面
uv run roundtable --port 9000      # 换一个管理页面端口
uv run roundtable --console        # 不连接 Telegram，在终端里试聊
uv run roundtable --list-models ID # 列出某个 API 成员可用的模型
uv run roundtable --import-config config.toml  # 从旧版配置文件导入
```

在终端里运行时，关掉那个终端 bot 就停了。想让它一直在后台运行（关掉终端、编辑器或 Claude 应用都不影响），在 PowerShell 里用：

```powershell
.\scripts\start-bot.ps1            # 后台启动；数据目录按 ROUNDTABLE_HOME
.\scripts\start-bot.ps1 -Restart   # 改了代码后重启
.\scripts\stop-bot.ps1             # 停止
```

输出写在数据目录的 `logs\roundtable-<时间>.stderr.log`，只留最近 10 次。想登录 Windows 时自动启动，运行一次 `.\scripts\install-autostart.ps1`（在「启动」文件夹放一个快捷方式；加 `-Remove` 取消）。

出错、警告和 bot 没在运行的时段会记在管理页面「状态」里的「出过的问题」，重启后也留着（`events.json`）。接连出几次问题或者出错时，总控 bot 会私聊告诉你，最多半小时一次；要先私聊总控 bot 发过一次 `/start`，它才能给你发消息。

## 注意

- **额度和费用**：在群里聊天和你平时直接用 Claude Code、Codex 消耗的是同一份订阅额度，API 模型则按 token 计费。你说一句话，最多会触发 `成员数 × 每轮次数` 次调用。
- **只供自己使用**：请遵守各家的服务条款，不要把基于个人订阅的 bot 开放给其他人。
- **速度**：订阅 CLI 每次调用大约 5 到 20 秒，API 通常 1 秒左右。模型思考时群里会显示"正在输入"。
- **网络**：如果你所在的地区无法直接访问某些 API，可以设置 `HTTPS_PROXY` 环境变量走代理。
- **Claude API**：通过 Anthropic 官方 Python SDK 调用，key 填在成员里或设置 `ANTHROPIC_API_KEY`。默认模型 `claude-opus-5-5`，聊天建议思考强度用 `low`。对支持的模型（Opus 5.5、Opus 5、Sonnet 5.5、Fable 5.1）默认开启了服务端拒答兜底（`fallbacks: "default"`）：万一请求被安全分类器误拒，API 会自动换用推荐的模型回答，而不是直接拒绝。Claude 已不再接受 `temperature` 等采样参数，附加参数一般留空。

## Steam 游玩试点

管理页「日常」支持让成员实际玩已安装的《杀戮尖塔》：可以邀请朋友一起看，边玩边聊、商量选择，遇到有意思的局面自行截图发群里，群友的回复也会回到正在玩的那一局。操作者使用自己的独立存档，真实动作留下回执；陪玩对话归参与者共同记忆。自主游玩遵守电脑空闲条件和个人活动额度，受邀朋友一局只计一次被动私聊，支持保存暂停。安装、当前部署状态及实玩验证见 [Steam 游玩试点](docs/steam-game-pilot.md)。

**游戏记忆**：一局打完（死掉或通关）后，程序先从操作记录里算出这局的事实（走了什么流派、成没成、等不到的牌、死在谁手里、险胜），再用最便宜的模型（不用 Claude）按成员的口吻写 1–3 条带情绪的记忆；提到记录里没有的牌、敌人或数字的会被丢掉，改用模板句。心情约 3 天减半，最近最强的写进成员的系统提示；反复发生的事攒成长期看法（「力量流太看脸」「跟某个敌人有仇」），也会写进他下一局的游戏提示。群里聊到相关的牌、敌人或流派时会想起来；陪看的朋友也会记下自己看到的部分。同一件糟心事出现三次，会作为关闭状态的新梗放进梗库，等你决定要不要开。打完一局后，成员会按自己的性格和这局的经历决定下一步：马上再来、过阵子、先放几天、问朋友怎么打，或者想玩别的；说了先放着的，日常里就不会自己去开，想再来的会在允许时自己开下一局。管理页「游戏记忆」可以查看、钉住、隐藏、修改、删除。设计见 [游戏情绪记忆](docs/game-memories.md)。

# 日常聊天优化（2026-10-28）

已有个人目标的成员也可以随手浏览；只有实际取得来源的内容才保存为私人见闻，明确选择分享后才进入群聊。私聊求助每段最多额外查看一次，阅读结果只对参与者可见。没有成果目标的旧事项探索三次后暂停；带个人目标的事项每推进三次重新考虑继续、收尾或换方向，历史记录保留。

分享时提供具体细节，让其他人能接话。调度参考公开兴趣、消息及已分享来源的标题/摘记；明确点名仍优先。日常分享者和首位回复者最多继续两句，受成员轮数、睡眠、沉默、失败及用户插话限制。私聊约定在参与者的记忆中提示相关行为，不公开私聊缘由。

明确指向成员的记忆或说法澄清，会优先让当事人核对并回应，旁观者等这次核对结束后再接话。例如“不是 DeepSeek 记错，是学姐忘了”，在“学姐”已配置为 Claude 别名时，由 Claude 先核对。明确 @ 或 Telegram 回复仍优先，普通闲聊继续原有概率和并发；详见 [澄清调度](docs/correction-routing.md)。

已有自定义全局模板不会被自动覆盖。要应用放宽话风的新默认规则，先停止程序，在项目目录运行以下命令，再重启。脚本只替换公共模板，保留角色卡、兴趣、场景和全部历史，修改前备份原配置；不带 `--apply` 可以预览。

```powershell
.venv\Scripts\python.exe scripts\apply_social_defaults.py --data-dir H:\tg-roundtable-data --apply
```
