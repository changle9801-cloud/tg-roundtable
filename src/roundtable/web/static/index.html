提示词

每个模型收到的提示词依次是：它的角色卡（在「成员」里填写）→ 下面的群聊规则 → 群的背景设定 → 话题范围 → 联网搜索、记忆、表情包说明。

群的背景设定

给所有角色一个共同的语境，角色之间的关系会更自然。

要跟进的事 

        
你在群里提到以后的安排（面试、出差、看病……），成员会记下来，到时候在群里问一句。白天才问，每天最多 3 次。

        

          
          
          
        

        

      


      

        

          
群里的大事记 

          
        

        
每天晚上 11 点后，挑出当天的名场面记下来，大家聊天时可以翻旧账；当天形成的新梗会放进梗库。

        

      


      

        
梗库 

        
网上和群里流传的、关于成员和 AI 圈的梗，所有成员都看得到。成员闲逛、搜索时看到新梗会自己记进来（回复里写 [梗:…]，群里看不到）；你也可以手动添加或删掉。

工具

      
给成员接上外部工具（MCP 服务器），比如刷 X、看视频。只有你在这里勾选允许的工具能用，也只有分给它的成员能用；
        成员闲逛时会按你写的偏好去用，群里聊天时也能用。Claude、Codex、Grok 订阅成员可以用，API 成员暂不支持。
        本地命令在你的电脑上运行，远程服务在其服务器上执行。自带的「读帖子与订阅」只读取公开内容，不登录或发表评论。

      

      

    


    

      
见闻

      
每个角色自己上网刷到、记下来的东西，各自私有，到期自动忘掉。被问「在干嘛」时它们照这里回答，冷场时也会从这里挑一条分享。

      

    


    

      
日常

      
参加的成员各自关注一些事，可以继续了解、找群友私聊（会轮流找不同的人），也可以先歇着。
        事项和私聊跨天保留；看到的东西会记进「见闻」，想分享时才发到群里。参加日常的成员不再单独闲逛和主动发言，由这里统一安排。
