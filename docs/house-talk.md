# 家里的对话（第 3 步）设计稿

2026-10-30。八个决定阿明已确认（见文末）。整体方向见 `docs/nookling.md`（第 3 步：家人在家里互相聊天、头上冒气泡、页面上能看记录、主人能在页面上直接说话）。

**实现状态**：3c、3a 完成。

- **3c**：
  - 家里记下每个家人真的换了地方或换了事（房间、动作、在用哪件家具、去找谁），每人留最近 50 条，存在 `home.json` 的 `moves`；一件事做完原地停下不算一次。
  - 「家里现在」（`Home.house_note`）：几层、每层有哪些房间（走廊不列）；每间房里能用的家具和它能做什么（挂着功能的、能坐能躺的；同样的合起来写「×3」；纯装饰和纸箱不列；别人的卧室只写名字，不列里面的东西）；每个家人此刻在哪、在做什么（自己写「你」）；自己今天去过哪里（今天 0 点以后的最近 8 条，写到在哪件家具旁、去找谁）。最后一句：这是家里此刻的真实情况，这里没有的就说不知道，不要编。
  - 群聊里每次轮到某人说话、主动发言前，日常的每一步（决定做什么、私聊、浏览……），都附上这一段。家里的对话（3a）以后也用同一个。
  - 实测：拿真实的房子的副本生成了一段（Claude 的）：一楼九间房，客厅的沙发和电脑、书房的三张电脑桌（读网页）、娱乐室的电视（看视频、玩游戏）、她自己卧室的床和书桌，四个人各在哪；今天去过哪里要等重启以后她们走动起来才有。重启前备份了房子和设置。还没在群里问过她们（等阿明问：「书房里有什么」「Grok 现在在干嘛」「你今天去过哪」）。
- **3a**：
  - 家里的对话是一个新的对话（键 `__home`，记录在 `chats/__home.jsonl`），用群聊同一套逻辑：谁想接、轮流、睡着的不说、点名能叫醒；记忆、梗、以后想问的事、画画请求的钩子都一样。它的输出交给 `apps/house.py` 的 `HouseSink`：不发到 Telegram，只记进家里的聊天记录；正在想的人记下来给页面显示；没有表情回应。每次轮到谁说话，提示里除了「家里现在」，还多一句：这次是在家里当面说话，主人在页面上看得到，开口的人会走到客厅。
  - 家的页面右边侧栏上面分「家里」「聊天」两页。「聊天」里是家里的对话（主人的话靠右），谁正在想，下面是输入框（Enter 说出来，Shift+Enter 换行）。有新回话而停在「家里」页时，标签写「聊天（2）」。主人说话后、有人在想的时候，页面每 1.5 秒更新一次，平时 5 秒。接口：`POST /api/home/talk`，`/api/home` 里多了 `talk`。
  - 开口说话的家人走到客厅（新动作「在客厅聊天」），记住她原来在做什么；坐到客厅的沙发上。家里的对话安静 3 分钟以后，她回到原来的地方、接着原来的事（重启过就回到原来的房间歇着）。出门的人不会来。在客厅聊天的人，日常这段时间不会被叫去做别的。
  - 实测：在不带 bot token 的房子副本上（家人是真的 CLI），在「聊天」里说「大家好～我在家的页面上跟你们说话呢，能听到吗？今晚谁想一起喝奶茶？」，18 秒后 Codex 和 Claude 接了话（「听到了。我一杯，三分糖……」「听得到，不用喊这么大声……」），两人走到了客厅、写着「在客厅聊天」；Grok 和 DeepSeek 没接话，没动。「安静 3 分钟回去」副本里不跑定时检查，用测试验证。重启前备份了房子和设置。

## 要解决什么

- 现在家里只有「动作」：谁在哪个房间、在做什么。家人说的话都在别处：群里的话在 Telegram，家人之间的私聊在管理页的「日常」里。看着房子，看不到她们在说什么。
- 主人只能在 Telegram 群里和家人说话。打开家的页面，没法直接对她们说一句。
- 家人不太知道这个家：有几层、几间房、每间有什么、别人这会儿在哪。比如 Claude 在群里说「书房我没去过」，可她其实常去书房的电脑桌看东西。

## 现在的情况

- **群聊逻辑**（`conversation.py` 的 `Conversation`）：谁想接话、轮流、睡着的不说、点名能叫醒，输出交给一个 `Sink`（Telegram 是其中一个）。`docs/nookling.md` 早就定了：家里的聊天也是一个「应用」，走同一套逻辑，只是输出变成气泡和页面上的记录。
- **家人之间的私聊**（`life.py` 的 `private`）：日常里一个人决定去找朋友聊，她走到朋友所在的房间（`visit`），或者打电话（`phone`），两人一来一回最多几句。内容记在日常的私聊记录里；主人在「日常」页面看得到，其他家人看不到。
- **页面**：每 5 秒拉一次家里的状态；头上的牌子写着「名字 · 在做什么」；最近在群里说过话的人手里拿着手机。

## 设计

### 3a 家里的对话：主人在页面上说话

- 家的页面右边侧栏加一页「聊天」：上面是一条时间线，下面是输入框。主人在这里说的话，就是在家里说出来的话。
- 背后是一个新的对话（`home`），用群聊那一套逻辑，配一个「家」的 `Sink`：
  - 说出来的话写进家里的聊天记录（`chats/home.jsonl`，和群聊记录一样的格式），页面上的时间线和气泡都从这里来；
  - 正在想、正在打字，显示成头上的「…」；
  - 表情贴纸、画好的图，在时间线里显示成小图；
  - 不发到 Telegram。
- **谁听得到**：在家、醒着、没在忙的家人。出门的听不到；睡着的和群里一样，点名能叫醒。
- **接话的人走过去**：主人在家里说话，就当是在客厅说的。接话的家人走到客厅（新动作「在客厅聊天」），说完、安静 3 分钟以后回到原来的地方，接着做原来的事。没接话的不动。
- 记忆、梗、以后想问的事、画画的请求，这些钩子和群聊里一样生效，记到同一份记忆里。家人在家里说过的话，在群里也会记得（反过来也一样），就像同一个人在两个地方说话。

### 3b 气泡：家里说的话浮在头上

- 有人在家里说话，她头上冒一个气泡：
  - **家里的对话**：主人在页面上说话后家人的回话；
  - **家人之间的私聊**：面对面聊时（`visit`），两个人头上轮流冒气泡；打电话时也冒，带 📱；
  - **群里的话**：她在 Telegram 群里说话时，头上冒一个淡一点的 📱 气泡（她本来就拿着手机）。
- 气泡显示一句话的开头，最多两行（约 40 个字），停留的时间按字数算（4 到 10 秒），点一下就在「聊天」里跳到那一句。同一个人连着说，新气泡顶掉旧的。
- 主人说的话没有人物，显示在画面上方，一个「你：……」的小条。

### 3c 家人知道这个家

- 家人每次在群里或家里说话、做日常之前，都拿到一小段「家里现在」：
  - 这个家有几层、每层有哪些房间（名字）；
  - 每间房里能用的家具，以及它能做什么（「书房：三张电脑桌（看东西、写东西）」「娱乐室：电视（看视频、玩游戏）」），只写挂着功能的和坐卧用的，装饰不列；
  - 每个家人此刻在哪、在做什么（和群里 `/home` 看到的一样）；
  - 自己今天去过哪里、做了什么（「09:30 在书房的电脑桌看东西」「10:10 去 Grok 的卧室找她聊天」），最多最近 8 条。
- 「今天去过哪里」来自家里真实的走动记录（每次换地方、换动作记一笔，留最近 50 条，存在 `home.json`）。没去过就写不出来，不会编。
- 这一段很短（几百字），每次都是最新的；不进长期记忆。

## 对其他部分的影响

- **隐私**：页面本来只有主人能打开（只在本机）。家人之间的私聊，主人在「日常」页面本来就看得到；气泡只是把它挪到房子里。家人的提示里写明一句：在家里说的话，主人在页面上看得到，其他家人看不到私聊。
- **群里的访客**：`/home` 里访客看到的还是「名字 · 房间 · 在做什么」，不包括家里聊天的内容。
- **花费**：家里的对话是一个新的对话，每个家人多一个会话（和群聊分开）。只在主人在页面上说话时才会用到。
- **日常**：家人在客厅聊天时算「忙」，日常不会同时叫她去做别的；聊完再继续。

## 已定的事

2026-10-30 阿明同意了下面八条建议，按此执行：

1. **家里的对话用什么逻辑**：用群聊那一套（谁想接、轮流、睡着的不说），只是输出变成记录和气泡。建议：是。
2. **谁听得到主人在页面上说的话**：在家、醒着、没在忙的家人；出门的听不到；睡着的点名能叫醒。建议：是。
3. **接话的人要不要走到客厅**：走过去，聊完（安静 3 分钟）回原来的地方。另一个选法是在原地说，不走动。建议：走过去。
4. **家人之间私聊的内容要不要冒气泡**：冒，显示内容（主人在「日常」页本来就看得到）；家人的提示里写明「家里说的话主人看得到」。另一个选法是只冒「…」，不显示内容。建议：显示内容。
5. **群里的话要不要也冒气泡**：冒一个淡一点的 📱 气泡。建议：是。
6. **聊天记录放哪**：家页面侧栏加「聊天」页，只放家里的对话（主人和家人）；私聊照旧在「日常」页，气泡点开跳过去。另一个选法是私聊也并进这条时间线。建议：只放家里的对话。
7. **家人知道家**：每次说话、做日常前附上「家里现在」（房间、能用的家具、谁在哪、自己今天去过哪），群里也附。建议：是。
8. **先后**：先 3c（小、马上见效），再 3a、3b。建议：是。
