  - 管理页多了「包」页面：装一个包（选文件 → 预览 → 装上 / 不装）、导出家具（勾选、包的名字、作者、许可证、说明 → 下载 `.nookpack`）、装过的包（卸载）。接口：`GET /api/packs`、`POST /api/packs/preview`（文件本身）、`POST /api/packs/install`、`POST /api/packs/export`（返回 zip）、`DELETE /api/packs/{uid}`。

- **5b**：

## 要解决什么

`docs/nookling.md` 的原则之一：「一切都能自己做、能分享」——家具、地砖、墙纸、壁画、家人模板、房间模板，打成包，别人下载就能装。

现在能自己做的已经很多了：自己做的家具种类（可以带 `.glb` 模型）、地板和墙的颜色或图片、画框里的图、房间的布置、家人的角色卡和外形。但它们都只在这台电脑上，没法给别人，也没法从别人那里拿。

## 包长什么样

一个包是一个 `.nookpack` 文件（其实是 zip），里面只有数据：

```
manifest.json      这是什么包、叫什么、谁做的、版本、许可证、需要哪些功能名、里面有什么
preview.png        预览图（可选；导出时自动画一张）
models/*.glb       模型（可选）
textures/*.png     图片：地砖、墙纸、画框里的画（png / jpg / webp）
```

四种包：

- **家具**：一种或几种家具（样子、大小、高度、颜色、用途、放地上还是挂墙、默认挂的功能名、标签、模型）。
- **表面**：几张图片，用作地板、墙纸、或画框和海报里的画。
- **房间**：一间布置好的房间：大小、地板墙面、里面每件家具摆在哪；用到的自己做的家具和图片都打在同一个包里，内置家具只写名字（每个家都有）。
- **家人**：一位家人的角色卡（名字、一句话介绍、身份性格、说话方式、对别人的看法、例句、作息、外形描述）和外形（颜色、配饰、模型）。

## 包里不能有的

- **程序**：没有代码、脚本、可执行文件。只认上面那几种文件，别的一律拒绝整个包。
- **密钥和账号**：家人包里没有 bot token、API key、用哪个 AI、怎么启动它；也没有她的记忆、日记、聊天记录。
- **外部网址**：模型不能引用外部网址（和现在上传模型一样的检查）。
- **MCP 工具**：包只能写「这件家具需要 `video.watch` 这个功能」。装哪个工具、给它什么权限，永远是你自己在「工具」页面决定；装包不会下载或运行任何东西。

导入时的检查：整个包最多 60 MB，最多 200 个文件；每个模型最多 50 MB、每张图片最多 5 MB（和现在上传的一样）；文件名里不能有 `..` 或绝对路径；解压后的总大小也有上限（防压缩炸弹）；`manifest.json` 每一项都检查类型和长度；功能名只认 `video.watch` 这种格式。不合格就整个不装，告诉你哪里不对。

## 怎么用

管理页多一个「包」页面：

- **导入**：选一个 `.nookpack` 文件 → 看预览：名字、作者、版本、许可证、里面有什么（家具有小图和转着的预览，图片直接显示）、需要哪些功能、其中哪些你还没连上工具 → 点「装上」。
  - 家具装成「我做的」家具（新的编号；重名的加「（2）」），图片和模型存进数据目录，和你自己上传的一样。
  - 表面装成可选的图片：在房间外观、画框图片里能直接选。
  - 房间装成一间新房间，自动找地方接在走廊边上、开门，家具按包里的位置摆好（放不下的跳过并告诉你）。
  - 家人装成一位**新的、还没启用**的家人：角色卡和外形填好了，你在「成员」页给她选用哪个 AI、填 bot 之后再启用。
- **导出**：选要导出的东西——一种或几种「我做的」家具、几张上传过的图片、一个房间、一位家人——填作者名、许可证（默认 CC BY 4.0），下载一个 `.nookpack`。
- **已装的包**：列出装过的包、带来了什么；「卸载」去掉它带来的、还没被用上的家具种类和图片。用它建的房间、家人已经是你的了，不跟着卸载。

## 对其他部分的影响

- **数据目录**：多一个 `packs.json`（装过的包和它带来的东西）。
- **家具和图片**：装进来的和你自己做的一样，能改、能删、能再导出。
- **许可证**：包里写明许可证，导出时选（CC0、CC BY 4.0、CC BY-SA 4.0、保留所有权利）。代码仍按 `docs/nookling.md` 决定 6，代码和内容分开授权。

| 块 | 内容 | 验收 |
| --- | --- | --- |
| 5a | 包的格式和导入检查；家具包：导出「我做的」家具（带模型）、导入、预览、已装列表、卸载 | 导出一种带模型的家具，在一个空的家里导入，预览里看得到、装上后能摆、需要的功能提示没连上；改坏的包（多一个 `.js`、`..` 路径、超大）被拒并说明 |

## 已定的事

2026-10-30 阿明同意了下面九条建议，按此执行：

2. **四种包**：家具、表面、房间、家人；房间包自带用到的自己做的家具和图片（不去引用别的包）。建议：是。

5. **重名和重复装**：装进来的家具总是新的一份（重名加「（2）」）；同一个包再装一次也是新的一份，不覆盖。建议：是。
