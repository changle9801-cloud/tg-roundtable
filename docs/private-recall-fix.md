# 私聊记忆在旧会话中的更新

2026-10-28 实际问题：Claude 在与 DeepSeek 的私聊中讲过鲸岛传说，公开群聊后来却否认。私聊原文在 life.json 和最新系统提示词预览中都存在；实际送入旧 CLI 会话的本轮输入只有公开群消息。

隔离诊断复现：已建立的 Claude CLI 会话只更新 system-prompt-file 时回答“不知道”；新会话能读到更新；把同一条记忆放进旧会话的当前输入后能正确回答。这一结果来自当前安装的 CLI，不推广为所有版本的永久行为。

修复：

- 参与者在发送当前轮输入前，通过动态回调检索自己实际参加过的私聊。Claude、Codex、Grok 的 CLI 输入和 API 当前请求都经过该路径。没有清空原有会话、聊天或私聊记录。
- 从全量历史中挑选与本轮话题相关的对话，并保留近期对话、约定候选；最多四段、约 6500 字符。原话明确标记本人、对方和完整日期。较老的相关私聊不再受系统提示词最近四段窗口限制。
- 只给参与者提供相应记录，提示其只回应被问到的部分。记录证明说过什么，不把当时的知识或猜测自动视为已核实事实。
- API 只在当前请求中附加该记忆，不把整段提示反复写入保存的聊天历史。

验证：361 项测试通过，覆盖更新后的记忆进入三个 CLI 的真实发送参数、API 请求与保存历史的分离、跨重启、旧记录检索和第三方隔离。隔离旧 Claude 会话在修复后成功读到了新加入的另一条记忆。
